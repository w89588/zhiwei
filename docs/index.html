WHAT YOU CAN DO

让信息有迹可循，
让记忆自然生长。

从日常会话到长期记忆，知微为个人使用而设计。不需要改变你的沟通习惯，只需在需要时找到它们。

01 / COLLECT
⌁

收集与同步

Windows 客户端只读解析本机微信数据，支持消息、图片、视频、语音和文件，并可断点续传。

02 / REMEMBER
✳

整理与回看

浏览会话和消息，选择关注对象，借助自选模型整理周期总结、关系记忆和个人画像。

03 / CONNECT
↗

连接你的 AI

通过 MCP 按授权范围查询消息与媒体，让你常用的 AI 工具获得需要的上下文。
