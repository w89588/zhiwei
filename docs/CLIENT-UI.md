# 客户端 UI 架构

## 模块边界

- `main.py`：启动本机服务、采集线程与固定 WebView2 窗口，管理退出。
- `helper/collector.py` / `collector_app.py`：服务端连接、微信解析与上传、运行统计；本机 HTTP 接口继续校验会话 token 和来源。
- `helper/desktop.py`：最小化、收起、退出、系统托盘、打开外部浏览器和剪贴板。仅通过桌面桥接提供系统操作。
- `helper/autostart.py`：当前 Windows 用户的启动项读写；与安装包共享 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\WechatHelper`，命令带 `--startup`。
- `helper/single_instance.py`：以数据目录区分的登录会话内单实例，重复手动启动唤回原窗口，重复开机启动静默结束。
- `helper/collector_static/collector.js`：导航、采集状态和表单；`api.js`：本地请求与提示；`desktop.js`：桌面功能适配。浏览器预览不启用原生窗口按钮和自启开关。

## 交互约定

窗口固定 840 × 640 逻辑像素；顶部标题、图标和空白区使用 pywebview 的专用拖动区域，最小化与收起按钮作为同级元素放在区域之外。全窗口拖动仍关闭，内容区域可正常点击和选择文字。无调整尺寸边框，禁用最大化和系统菜单的大小命令，保留移动命令，原生最小与最大尺寸一致。Windows 显示缩放继续生效。内容区域可滚动，错误摘要、较长状态或浏览器缩放不会遮挡表单。

四页为运行概览、连接设置、MCP 接入、软件设置。统计只使用服务端确认的消息变更数；连接中断会显示状态过期。MCP Key 仅保存在当前页面内存，不写入本地文件；渲染服务器返回的文本使用 `textContent`。

当前源码的同步范围为群聊与通讯录好友。`sync_scope.py` 集中管理筛选，`wechat.py` 根据联系人快照缓存分类，`platform_sync.py` 在加密前过滤会话清单、预览与联系人，并在分批读取时再检查范围。当前微信 4.x 联系人类型 1/5、好友位和非删除状态共同确认私聊对象；群成员条目、备注及历史会话映射不作为好友依据。公众号标记、`gh_` 账号、系统账号及 `biz_message_*.db` 不进入消息上传。缺少分类字段或联系人快照读取失败时暂停上传，避免沿用失效的好友清单。好友增删在下一轮快照生效；服务端已有数据不自动删除。`tests/test_sync_scope.py` 覆盖清单、预览、历史重传、成员发言、账号切换及读取失败的上传边界。此筛选从 v2.0.2 开始生效。

关闭窗口优先收起到托盘；只有成功创建托盘图标后才拦截关闭。托盘创建失败时保留窗口作为退出入口。`--startup` 先以最小化状态初始化，再在托盘成功创建后隐藏。

## 开机自启

首次安装的启动选项默认勾选，可以取消。覆盖安装只更新已有启动项的程序路径，不重新开启在软件中关闭的选项。卸载始终清理本应用的启动项，保留用户数据。

软件设置直接读取注册表实际状态，不使用另一个可能过期的布尔配置。写入失败保留原状态并显示失败提示。Windows 任务管理器禁用启动项时显示系统禁用说明，不改写系统批准状态。便携版和源码版可以手动开启；源码版使用当前环境的 `pythonw.exe` 和脚本绝对路径。移动便携目录后应重新开启自启以更新路径。

## 图标与验证

`app.svg` 是应用自身的几何图标，非微信官方标识。`tools/build-client-icon.ps1` 使用 Windows GDI+ 生成 16、20、24、32、48、64、128、256 像素 ICO；同一资源用于 EXE、安装包、窗口与托盘。

设计约定见 `design-system/wechat-collector/MASTER.md`。`tests/test_desktop.py` 使用模拟注册表验证启动项权限、开关、错误回退和命令路径，并验证 Windows 单实例唤回。`tools/verify_desktop_shell.py` 使用隔离窗口验证原生尺寸约束、托盘、收起/恢复和 `--startup`。

`tools/verify_installer.ps1` 仅在不存在同标识安装和启动项时执行安装/升级/卸载检查。本机已有安装时，先用 `tools/build-installer-qa.ps1` 构建只替换安装标识、注册表名和快捷方式名的测试副本，再运行验证脚本的 `-IsolatedIdentity` 模式。测试副本保留相同程序文件与安装逻辑，并在结束时卸载。
