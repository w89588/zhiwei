# 数据与隐私边界

知微面向个人自部署，不是平台无法访问内容的零知识服务。部署者有责任控制服务器、本机、模型服务及备份的访问权限。

- 客户端在 Windows 本机只读解析微信数据库，不上传微信数据库解密密钥，但会生成可读取的本机解密缓存；同一用户下的程序和管理员可能访问该缓存。
- 同步覆盖群聊和通讯录好友私聊，可能包括历史记录及图片、视频、语音、文件实际内容；具体取决于本机文件、授权和微信版本。筛选变化不会自动清除既有服务端记录。
- 消息批次和服务端敏感内容使用加密，服务端主密钥存于服务运行配置。服务端需解密以查询和调用模型；持有主密钥和数据的服务器管理员可读取内容。部分标识、时间、数量及任务状态等元数据不一定加密。
- 已配置模型分析时，相关聊天及媒体会发送到模型服务商；请自行审查其隐私政策与费用。MCP Key 的持有人可按授权访问数据。
- HTTPS 保护连接；HTTP 不能保护凭据和网络传输，即使消息批次本身加密也不等于所有通信加密。
- 备份和主密钥须配套恢复，但建议分开保护；不要公开 `.env`、数据备份、日志、MCP Key 或截图中的真实对话。
- 公开演示站仅使用虚构数据、不连接实际服务，不支持注册或上传。
