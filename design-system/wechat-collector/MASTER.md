# 微信解析客户端设计约定

基于 ui-ux-pro-max 的 Minimalism & Swiss Style、密度 9 的建议，采用适合 Windows 采集工具的浅色紧凑布局。搜索结果中的营销落地页、试用 CTA 与在线字体不适用于本项目，未采用。

- 原生窗口为 840 × 640 逻辑像素，无边框、不可缩放、不可最大化。顶部标题、图标与空白区可拖动窗口；右侧控制按钮和页面内容不属于拖动区域。Windows DPI 缩放继续生效。
- 52px 标题栏、168px 导航、28px 底部状态栏。页面内容独立滚动，错误提示或系统缩放不截断表单。
- 功能限于运行概览、连接设置、MCP 配置复制、软件设置；服务端通过外部浏览器打开。
- 背景 `#f5f7f8`，表面 `#ffffff`，主文本 `#1d302d`，次文本 `#576b66`，操作色 `#166553`，错误色 `#a12d25`。颜色语义在 CSS 变量统一定义。
- 使用 Windows 自带 Segoe UI / Microsoft YaHei UI，无网络字体；正文 12–13px，辅助文本 10–11px，页标题 21px。
- 图标为统一 1.7px 线条 SVG；应用图标是自有几何图形，不使用微信官方标志。Windows ICO 包含 16–256px 八个尺寸。
- 4/8px 为基础间距，面板间距 14px，页内边距 24px。动画仅用于 140ms 状态反馈，尊重 reduced-motion。
- 状态同时有文字与颜色，等待、异常、成功、状态过期明确区分；统计来自服务端确认，未连接不展示模拟成功。
- 表单保留粘贴能力；字段错误与摘要关联，失败后聚焦摘要。键盘焦点可见，按钮不会因 hover 改变尺寸。
- 开机自启开关读取系统实际注册；Windows 禁用启动项时显示说明，不越过系统设置。浏览器预览禁用桌面操作。
- 关闭按钮收起到托盘；托盘故障时仍能退出，开机启动不会隐藏一个无托盘入口的窗口。

验证目标：固定窗口下四页正常显示；初始/成功/失败/状态过期；连接与账号选择；MCP 复制；自启成功/失败反馈；键盘焦点；缩放和窄浏览器预览不横向溢出。
